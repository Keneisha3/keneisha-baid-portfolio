# Keneisha Baid Portfolio

Live Site: https://keneisha-baid-portfolio.vercel.app

Access all my best projects above! 

## About

This portfolio showcases my work as a Management Engineering student at the University of Waterloo with experience in software development, machine learning, data analytics, project management, and interactive digital design.

The site was built to go beyond a traditional portfolio by creating an interactive experience where visitors can explore technical projects, professional experience, leadership roles, and creative work. It highlights both technical skills and the ability to communicate ideas through engaging user experiences.

The portfolio includes software engineering projects, machine learning applications, data visualization tools, interactive artwork, and a virtual reality experience that presents my background and interests in a unique format.

## Features

### Project Showcase

A collection of projects covering machine learning, finance, data analytics, software development, and web technologies. Each project includes details about the problem, approach, technologies used, and outcomes.

### Portfolio Chat Assistant

A client-side chat assistant that allows visitors to learn more about my experience, projects, skills, and interests.

### Skills Visualization

Interactive charts and visualizations that provide an overview of technical skills, tools, and areas of experience.

### Interactive Drawing Experience

A drawing application built with p5.js that allows visitors to create artwork directly within the site.

### Virtual Reality Gallery

A 3D experience built with A-Frame that gives visitors an interactive way to explore my projects, experiences, and interests.

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The production build is generated in the `dist/` directory.

## Deployment

The application is deployed on Vercel and can be hosted on any static hosting platform that supports modern React applications.

## Purpose

The goal of this project was to create a portfolio that reflects both technical and creative work. It brings together software engineering, machine learning, data visualization, project experience, and interactive design in a single platform that allows recruiters, employers, and collaborators to learn more about my background.
