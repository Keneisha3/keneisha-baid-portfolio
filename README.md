# Keneisha Baid — Portfolio

My personal portfolio: a single-page site built with React, Vite, and Tailwind CSS.

## Tech

- React + Vite
- Tailwind CSS
- Framer Motion for animations
- Recharts for the skills radar
- p5.js for the interactive doodle
- A-Frame for the 3D "Step inside my brain" gallery

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy

It's a static site, so it deploys to Vercel (or any static host). Connect the
repo and Vercel auto-detects Vite (build command `npm run build`, output `dist`).

The chat widget is fully client-side, a small built-in Q&A, so there are no API
keys or backend to configure.

## Shared travel recommendations (optional backend)

The travel map lets visitors drop recommendation pins. By default these save in
each visitor's own browser (local only). To make them **shared** — so everyone
sees everyone's pins — connect a free Supabase project:

1. Create a project at https://supabase.com (free tier).
2. In the SQL editor, run:

   ```sql
   create table travel_recs (
     id bigint generated by default as identity primary key,
     name text not null,
     lat double precision not null,
     lng double precision not null,
     created_at timestamptz default now()
   );
   alter table travel_recs enable row level security;
   -- allow anyone to read pins
   create policy "read pins" on travel_recs for select using (true);
   -- allow anyone to add a pin
   create policy "add pins" on travel_recs for insert with check (true);
   ```

3. In **Project Settings → API**, copy the **Project URL** and the **anon
   public** key.
4. Paste them into `SUPABASE` in `src/data/portfolio.js`:

   ```js
   export const SUPABASE = {
     url: "https://YOUR-PROJECT.supabase.co",
     anonKey: "YOUR-ANON-KEY",
   };
   ```

5. Redeploy. The map switches to shared mode automatically; if the backend is
   ever unreachable it falls back to local-only so the feature never breaks.

The anon key is safe to expose in frontend code — row-level security limits it
to reading and inserting pins only.
